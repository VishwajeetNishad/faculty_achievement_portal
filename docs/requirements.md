# System Requirements Specification (Hardware & Software)

**Institution**: Noida Institute of Engineering and Technology (NIET)  

---

## 1. Development Requirements

- **Operating System**: Windows 10/11 64-bit, macOS 13+, or Linux Ubuntu 22.04 LTS
- **JDK**: Eclipse Adoptium OpenJDK 21 LTS
- **IDE**: VS Code / IntelliJ IDEA / Eclipse
- **Database**: MySQL Community Server 8.0+
- **Build Tool**: Apache Maven (mvnd 1.0.6)
- **REST Client**: PowerShell 5.1+ / Postman / cURL

---

## 2. Production Deployment Requirements

- **Server Hardware**:
  - **CPU**: 4 Cores (x86_64)
  - **RAM**: 8 GB RAM Minimum (16 GB Recommended)
  - **Disk Space**: 100 GB SSD Storage
  - **Network**: 100 Mbps Dedicated Ethernet / Internet Link
- **Server Software**:
  - **OS**: Ubuntu Server 22.04 LTS (64-bit)
  - **Java**: OpenJDK 21 Headless JRE / JDK
  - **Database**: MySQL Server 8.0+
  - **Web Server**: Nginx 1.18+ (SSL/TLS Enabled)
  - **SSL**: Let's Encrypt / Institutional SSL Certificate
