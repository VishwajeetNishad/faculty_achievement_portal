# Screenshot Capture Checklist & Documentation Guidelines

**Institution**: Noida Institute of Engineering and Technology (NIET)  

---

## 1. Required Screenshots Checklist for Final Project Report

When assembling the printed college project report and final presentation slides, capture screenshots of the actual running application for the following 15 key interfaces:

1. **Landing / Portal Overview Page** (`frontend/pages/index.html`) — Hero banner, features grid, institution branding.
2. **User Authentication Interface** (`frontend/pages/login.html`) — Login card, institutional domain branding, validation states.
3. **Faculty Personal Dashboard** (`frontend/pages/dashboard.html`) — Total metrics, category pie chart, pending/approved counts, recent submissions table.
4. **Achievement Creation Form** (`frontend/pages/add-achievement.html`) — Category selector, dynamic category fields, date pickers.
5. **Faculty Achievement Records Roster** (`frontend/pages/achievements.html`) — Search toolbar, status badges, action buttons.
6. **Achievement Detail Modal** — Complete achievement metadata, proof URL link, verification history.
7. **PDF Proof Upload Modal** — File selector, PDF file size indicator, upload progress/success state.
8. **Faculty Self-Profile Page** (`frontend/pages/profile.html`) — Editable profile fields, designation, phone, tamper-proof role display.
9. **HOD Departmental Dashboard** — Department statistics, faculty participation count, pending verification queue.
10. **HOD Achievement Verification Modal** — Reviewer feedback text area, Approve/Reject action buttons.
11. **Admin Control Center Dashboard** (`frontend/pages/admin/dashboard.html`) — Institution-wide analytics, department comparison table.
12. **Admin Institutional Faculty Roster** (`frontend/pages/admin/faculty.html`) — Faculty list, department filter dropdown.
13. **Institutional Audit Trail** (`frontend/pages/admin/audit-logs.html`) — Action badges, actor emails, IP addresses, date range filters, pagination.
14. **In-App Notification Panel** — Slide-over drawer, unread badge counter, notification action links.
15. **Mobile Viewport Responsive Layout (375px / 768px)** — Mobile navigation drawer, stackable cards, responsive tables.
