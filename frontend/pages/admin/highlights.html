Homepage Highlights

View Homepage
These banners are the first thing a visitor sees. They sit at the very top of the public homepage and slide automatically. The picture files are stored on the server, not in this page and not in the code — the database keeps only the file name, the alt text and the order. Banners are institute publicity: they are separate from verified achievement records and are not counted in any statistic.

Add Banner

PNG, JPEG or WebP, up to 2 MB. The frame is 1600 × 1172 (the same 1.365:1 shape niet.co.in cuts its banners to), so a picture at that size or larger fills it with nothing cropped. The server checks the file itself, so renaming a file does not change what it is.

Choose a picture to see exactly what the homepage banner will show.

The banner is wide, so a tall picture loses its top and bottom. This is the desktop shape; on a phone the frame is taller and crops the sides instead.
